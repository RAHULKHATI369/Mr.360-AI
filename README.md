## 🚀 Project Overview
**Mr. 360 AI** is a sophisticated multimodal AI solution engineered to solve real-world stadium bottlenecks. Originally conceptualized under the **MindPulse AI** umbrella, this project utilizes **Gemini 1.5 Flash** and **FastAPI** to provide a 360-degree intelligence layer for live sports.

Developed and deployed within a high-pressure 300-minute sprint, Mr. 360 AI represents the pinnacle of rapid "Agentic" development.

---

## 🛠️ Core Intelligence Modules

### 1. 📊 Tactical Analysis Layer
*   **Real-Time Computer Vision:** Processes live match feeds to identify shot selection (Cover Drive, Pull, etc.).
*   **Trajectory Mapping:** Analyzes ball length and pitch-point distribution using specialized AI logic.

### 🎙️ 2. Smart Commentary (Broadcasting)
*   **Hinglish Context Engine:** A custom NLP layer that generates witty, localized commentary.
*   **Multi-Device Sync:** Integrated via Firebase Firestore for seamless real-time audio broadcasting.

### 🚪 3. Crowd Dynamics (Gate Advisory)
*   **Congestion Mapping:** Real-time analysis of Rajiv Gandhi Stadium entrance gates.
*   **Smart Routing:** AI-driven suggestions to redirect fans to less crowded gates (e.g., Gate 4 vs Gate 7).

### 🍔 4. Food Analytics (Quality Score)
*   **Visual Gastronomy AI:** Point the camera at stadium food to receive a real-time quality and portion-size rating based on hygiene and presentation.
